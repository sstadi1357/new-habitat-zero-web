# New Habitat Zero (web build)

Play it: **https://sstadi1357.github.io/new-habitat-zero-web/**

This repo only holds the exported web version of New Habitat Zero, a 2D pixel-art game made in
Godot 4.7. You live on a moon base for 5 days, picking tasks and surviving moon dust, a leak, a
solar flare and a moonquake.

Controls: WASD / arrow keys to move, Tab for the task board, E to use a machine.

Credits: Moon tileset by TheRealFusion (Moonbase pack). Science background from NASA (links in
the game's How to Play page).
